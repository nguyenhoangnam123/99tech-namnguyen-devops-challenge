# 05 nginx resolves the API address only once, at startup

Code at da461c3 (port fixed, nothing else); scripts from this branch.

## A: the API comes back at a new address

The API restarts while another container takes its old address (here a placeholder;
in practice any container joining the network).

$ curl localhost:8080/api/users
200
API address: 172.27.0.4

$ docker compose stop api
 Container problem3-api-1  Stopped
$ docker run -d --rm --name p3-ip-holder --network problem3_default alpine:3.20 sleep 300
placeholder address: 172.27.0.4
$ docker compose start api
 Container problem3-api-1  Started
API address: 172.27.0.6

$ docker exec problem3-nginx-1 getent hosts api
172.27.0.6      api
$ curl localhost:8080/api/users   (x3)
502 502 502 
$ docker compose logs nginx | tail -1
connect() failed (111: Connection refused) while connecting to upstream, request: "GET /api/users HTTP/1.1", upstream: "http://172.27.0.4:3000/api/users"
