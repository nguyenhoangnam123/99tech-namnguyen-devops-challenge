## The API process killed from outside, as the OOM killer would

running, restarts 1, restart policy "unless-stopped"
$ curl localhost:8080/api/users
200

## Stopping the API

$ /usr/bin/time -p docker compose stop api
 Container problem3-api-1  Stopped
real 0.39
$ docker inspect problem3-api-1
exit code 0

With a request that never finishes (headers half sent from inside the container):
$ docker compose exec -T api node -e '<open 127.0.0.1:3000, send half the headers, wait>' &
$ /usr/bin/time -p docker compose stop api
 Container problem3-api-1  Stopped
real 8.27
$ docker inspect problem3-api-1
exit code 1 (forced exit after 8 s)

For comparison, a kill sent through Docker counts as a manual stop:
$ docker kill problem3-api-1
$ docker inspect problem3-api-1   (3 s later)
exited, restarts 0 (was 0)
