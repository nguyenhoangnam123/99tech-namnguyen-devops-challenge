# 08 A frozen Postgres holds requests for as long as it is frozen

Load: 50 req/s on /api/users for 60 s; `docker compose pause postgres` for 20 s.
Code as of the fixes for 01 to 07. statement_timeout is enforced by Postgres itself,
so a frozen server never applies it: the 10 requests holding connections wait it out.
The rest fail after the 2 s pool wait. A freeze over 60 s would end in nginx 504s.
